# HTML & CSS Landing Page

A simple landing page built using HTML and CSS while learning frontend development.

## Technologies Used

- HTML5
- CSS3
- Remix Icon

## Concepts Practiced

- Semantic HTML
- CSS Flexbox
- Spacing and alignment
- Background images
- CSS positioning
- Border radius
- Buttons and navigation
- Basic webpage layout

## About

This project was created as a practice project to apply the HTML and CSS concepts I learned and build a complete webpage layout from scratch.
